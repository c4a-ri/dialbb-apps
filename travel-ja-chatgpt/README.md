# 旅行インタビュー対話アプリケーション

- DialBB ver. 1.1+ で動作します． (ver. 1.0では動作しません）

## 概要

- ChatGPT組み込み対話ブロックを用いて旅行に関するインタビューを行う日本語対話アプリケーション


## 実行方法

このREADMEのあるディレクトリで以下を実行してください．
```
dialbb-server config_ja.yml
```

ブラウザで`http://localhost:8080`または`http://localhost:8080/test`にアクセスして対話してください．

## 対話例

```
System: こんにちは．私の名前は渡辺翔太です．本日は旅行に関してインタビューさせてください．旅行には良く行かれますか？ 
User: はい，よく行きます 
System: 素晴らしいですね！最近行った旅行先はどこでしたか？ 
User: 京都です 
System: 京都は歴史的な魅力がたくさんありますね．特に印象に残ったスポットはありましたか？ 
User: 清水寺が良かったです．清水の舞台は素晴らしいですね 
System: 清水寺の舞台からの景色は本当に素晴らしいですよね．旅行先で何をするのが一番楽しいと思いますか？ 
User: やはり食事ですよね．おいしいものを食べると幸せになります 
System: 確かに，美味しい食事は旅行の楽しみの一つですよね．次に行きたい旅行先はどこですか？ 
User: 今回京都しか行けなかったので奈良に行きたいです 
System: 奈良も素敵な場所ですね！歴史や自然を感じられます．旅行の予約はどのようにしていますか？旅行代理店利用ですか，それともWebサイトですか？ 
User: Webサイトですね． 
System: 便利ですよね．Webサイトだと簡単に比較できるのが魅力です．何か特に重視するポイントがありますか？ 
User: ホテルは値段とユーザ評価を重視します 
System: それは重要なポイントですね．特に評価が良いと安心できますよね．旅行全体で，他に重視することはありますか？ 
User: なるべくゆっくり時間を取れるようにして，あちこち行き過ぎないようにします 
System: ゆったりした時間を持つのは大切ですね．旅行先でリラックスできると，より楽しめますよね．他に旅行で特に心がけていることはありますか？ 
User: 荷物を少な目にしようとしています 
System: 荷物を少なくするのは良い考えですね！軽いと移動も楽になりますし，身軽で行動できますよね．旅行の際に持って行く必需品は何ですか？ 
User: ちょっと羽織るものがあれば気温の変化に対応できていいですよ 
System: 確かに，急な気温の変化に対応できるのは大切ですね．羽織るものがあると安心です．旅行先での服装選びはいつも悩みますか？ 
User: 悩みますね．外は暑くてもお店に入ると冷房効きすぎてたりするので 
System: その通りですね．温度差が激しいと服装選びが難しいですよね．重ね着ができると便利ですが，どうしていますか？
...
```
