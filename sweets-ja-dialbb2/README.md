# お菓子インタビュー対話アプリケーション


DialBB ver 2.x で動作．（ver. 1.xでは動作しません）


## 概要

- 好きなお菓子やどこでお菓子を買うかなどをてユーザに尋ねるアプリケーション

- [ノーコードツール](https://c4a-ri.github.io/dialbb/no-code/index-ja.html)を利用して構築

## ファイル構成

  - `sweets-ja.zip`: DialBB-NCにそのまま読み込めるファイル

  - `sweets-ja`: 上記ファイルを展開してできるディレクトリ．これを編集して新しいアプリケーションを
作ることができる．

## 対話例

```
System: こんにちは、私はあおいと言います。お名前を教えていただけますか?

User: こんにちは、あおいさん。私の名前はさくらです。今日はどんなことを話しましょうか？

System: ありがとうございます。さくらさん。今日はお菓子について教えてください。普段お菓子はよく食べますか?

User: お菓子は大好きで、特に執筆中にリラックスするために食べることが多いです。最近はマカロンやグミ、クラッカーをよく楽しんでいます。お菓子の中でも、ラデュレのマカロンは特にお気に入りです。可愛い見た目に思わずテンションが上がりますよ。

System: わかります、可愛いですよね！どんなお菓子が好きですか?

User: 好きなお菓子はマカロン、グミ、そしてクラッカーです。特にマカロンは見た目が華やかで、味も色々楽しめるのが魅力的です。グミは噛むと弾ける感じが癖になりますし、クラッカーはしょっぱいおつまみ感覚で食べられるのが良いですよね。お菓子選びはいつも楽しいです！

System: いいですね！マカロンの種類、豊富ですよね。最近のおすすめはありますか？

User: 最近おすすめなのは、ラデュレの季節限定のフレーバーです。特に春に出る桜味のマカロンは、ほんのり甘くて香りも良くて、見た目もピンク色が可愛らしいんです。お花見のお供にぴったりだと思いますよ。こんな時期にぴったりのお菓子を楽しむのは幸せですね。

System: 春の桜味、素敵ですね！ちなみにお菓子はどんな時に食べますか?

User: お菓子は主に執筆中のリフレッシュタイムや、ちょっとした気分転換に食べることが多いです。特に集中しているときに甘いものを食べると、エネルギーがチャージされる気がします。あとは友達とお茶をしながらお菓子を楽しむのも最高ですね。お菓子を介して会話が弾むのが嬉しいです。

System: わかります、最高ですね！お菓子を食べると一息つけますね!

User: 本当にそうですね！お菓子を食べると、心がほっこりしてリラックスできます。甘いものを口にすると、ストレスも少し和らぐ気がします。だから、執筆の合間に自分へのご褒美として食べるのが楽しみなんです。お菓子って、ただの食べ物以上の特別な存在ですよね。

System: 本当にそうですね！お菓子の力ってすごいです。普段お菓子はどこで買いますか?

User: 普段はネット通販を利用して、海外の珍しいお菓子を注文することが多いです。特にラデュレや他の海外ブランドのお菓子は、店舗に行かなくても手軽に楽しめるのが嬉しいです。もちろん、たまには近くのカフェや専門店にも足を運んで、新しいお菓子を探すのも素敵な冒険です。お菓子を選ぶ時間は、ワクワクしますよね。

System: そうなんですね！ネット通販で海外のお菓子を楽しむのは素晴らしいですね。どんな珍しいお菓子を見つけたことがありますか？また、特に気に入ったものがあれば教えてください！

User: 最近見つけた珍しいお菓子は、フランスの伝統的なキャンディーで、フルーツフレーバーが絶妙なものです。特に好きなのは、ラベンダー味のキャンディーで、風味がとてもユニークでリラックスできます。それから、アメリカのスナック菓子も面白くて、バター風味のポップコーンや、スパイシーなチップスを試してみたりしています。新しい味を発見するのは、まるで宝探しのようで楽しいです！

System: 面白そうですね！では最後にもう一つだけ。小さいころに好きだったお菓子を教えてもらえますか?

User: 小さい頃は、やっぱりグミが大好きでした！特にフルーツの形をしたグミは、見た目が可愛くて、食べるときのワクワク感がたまりませんでした。友達と一緒に食べたり、いろんな味を集めたりするのが楽しかったです。今でも時々、昔の思い出を思い出しながらグミを食べることがあります。あの頃の甘い思い出を振り返ると、心が温かくなりますね。

System: グミ、懐かしいですね！フルーツの形が可愛くて、楽しい思い出がたくさんありそうですね。特にどのフレーバーが好きでしたか？また、友達と一緒に食べたエピソードなんかも聞かせてください！

User: 特に好きだったフレーバーは、イチゴとグレープでした！イチゴは甘酸っぱくて、グレープはジューシーな感じがたまらなくて。友達と一緒にお菓子パーティーを開いて、いろんなグミをシェアしながら、どれが一番美味しいかを競ったりしました。そんな時に、みんなで「これが一番だ！」って盛り上がるのが楽しくて、笑いが絶えない思い出です。お菓子を通じて、友情も深まった気がします！

System: グミの思い出、素敵ですね！友達とお菓子パーティーは楽しそう。イチゴとグレープのフレーバー、どちらも魅力的です。お菓子を通じての交流は本当に特別なものですね。

さて、そろそろお時間です。お話できて楽しかったです！ 今日はありがとうございました。
```
