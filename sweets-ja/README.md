# お菓子インタビュー対話アプリケーション


DialBB ver 1.0+ で動作．


## 概要

- 好きなお菓子やどこでお菓子を買うかなどをてユーザに尋ねるアプリケーション

- DialBB ver1.1以上が必要

- [ノーコードツール](https://c4a-ri.github.io/dialbb/no-code/index-ja.html)を利用して構築

## 対話例

  ```
  システム: こんにちは，私はあおいと言います．お名前を教えていただけますか？
  ユーザ: 柏倉レイナです．よろしくお願いします，あおいさん！
  システム: ありがとうございます．レイナさん．今日はお菓子について教えてください．
            普段お菓子はよく食べますか？
  ユーザ: はい，毎日食べますね．職場のデスクにも必ずお菓子を置いています．癒しみたいなものです．
  システム: わかります！癒しですよね．どんなお菓子が好きですか？
  ユーザ: 銘菓が好きですね．特にモロゾフのカスタードプリンは小さい頃からのお気に入りです．
  システム: いいですね！おいしいですよね．おやつにスイーツ嬉しいですね！
  ユーザ: そうなんです．特に疲れたときに食べると，ほっとするんですよね．モロゾフのプリンは
          その点で最高です．
  システム: わかります，その気持ち！ちなみにお菓子はどんな時に食べますか？
  ユーザ: 仕事の合間や休憩中によく食べますね．一息つきたい時にちょうどいいんです．
          家では夜に食べることが多いです．
  システム: わかります，その気持ち！おうちだとリラックスできますよね！
  ユーザ: そうなんです．家でお菓子を食べる時間は，1日の中でも特にリラックスできる時間です．
  システム: そうなんですね！リラックス大事ですよね．普段お菓子はどこで買いますか？
  ユーザ: 近くのスーパーだと欲しいものがないので，主にネット通販で買っています．便利なんですよね．
  システム: そうなんですね！ネット通販便利ですよね．どのサイトをよく利用していますか？
            また，お気に入りのお菓子を見つけるコツなどあれば教えてください．
  ユーザ: 私は楽天やAmazonをよく利用しますね．レビューを見て評判の良いものを試してみるのが
          コツです．あと，期間限定品も要チェックですよ！
  システム: なるほど，参考になります！では最後にもう一つだけ．小さいころに好きだったお菓子を
            教えてもらえますか？
  ユーザ: モロゾフのカスタードプリンはもちろん，小倉山荘のおかきも好きでしたね．おばあちゃんが
          よく買ってくれたんです．懐かしい思い出です．
  システム: 懐かしいですね！おばあちゃんとの思い出，素敵です．小倉山荘のおかきはどんな味が
            好きでしたか？また，どんなシーンで食べていましたか？
  ユーザ: 塩味のシンプルなおかきが特に好きでしたね．家族でお茶を飲みながら食べるのが定番の
          シーンでした．おばあちゃんが入れてくれるお茶と相性抜群でしたよ．
  システム: お茶とおかき，最高の組み合わせですね！おばあちゃんとの思い出，心温まります．
            さて，残念ながらお話の時間が来てしまいました．またお菓子についてお話しできると
	    嬉しいです！ 今日はありがとうございました．
  ```

## ファイル構成

  - `sweets-ja.zip`: DialBB-NCにそのまま読み込めるファイル

  - `sweets-ja`: 上記ファイルを展開してできるディレクトリ．これを編集して新しいアプリケーションを作ることができる．


## シミュレーションによるテスト

bashの場合

```sh
export OPENAI_KEY=<OPENAIのAPIキー>
dialbb-sim-tester --app_config sweets-ja/config.yml --test_config simulation/simulation_config.yml --output _output.txt
```
