# 旅行インタビュー対話アプリケーション

- DialBB ver. 2.0+ で動作します． (ver. 1.xでは動作しません）

## 概要

- ChatGPT組み込み対話ブロックを用いて旅行に関するインタビューを行う日本語対話アプリケーション


## 実行方法

このREADMEのあるディレクトリで以下を実行してください．

```sh
(Windowsの場合) set OPENAI_API_KEY=<別途取得したOPENAIのAPIキー>
(Linux/Macのbashの場合) export OPENAI_API_KEY=<別途取得したOPENAIのAPIキー>
dialbb-server config.yml
```

ブラウザで`http://localhost:8080`または`http://localhost:8080/test`にアクセスして対話してください．

## ユーザシミュレーション

```sh
dialbb-sim-tester --app_config config.yml --test_config simulation/config.yml
```


## 対話例

```
System: こんにちは。私の名前は渡辺翔太です。本日は旅行に関してインタビューさせてください。旅行には良く行かれますか？
User: 年に二回ほど旅行に行きます。最近はハワイに行きました。リフレッシュできました。
System: ハワイに行かれたんですね！特に印象に残った場所はありましたか？
User: ワイキキビーチが特に印象に残っています。静かな時間を過ごせました。海もきれいでした。
System: ワイキキビーチは素晴らしいですね！他に楽しかったアクティビティはありましたか？
User: シュノーケリングを楽しみました。色とりどりの魚を見ることができて、癒されました。家族みんなで楽しめました。
System: シュノーケリングは楽しそうですね！次に行きたい旅行先はありますか？
User: オーストラリアに行ってみたいです。自然が豊かで、のんびりできそうです。特にグレートバリアリーフに興味があります。
System: オーストラリアのグレートバリアリーフ、素敵ですね！予約はどうされますか？
User: 旅行代理店に電話して予約します。直接話すのが安心ですから。プランを相談しながら決めます。
System: 旅行代理店に直接相談するのは良い方法ですね！他に旅行に行かない理由はありますか？
User: 特にないです。仕事が忙しい時期もありますが、時間ができれば行くようにしています。家族との時間も大切にしたいです。
System: 家族との時間、大切ですね！旅行での思い出は素敵です。次に行きたい場所は何ですか？
User: オーストラリアの次にニュージーランドにも行きたいです。自然が美しいと聞いていますし、のんびり過ごせそうです。
System: ニュージーランドも魅力的ですね！特に行きたい場所はありますか？
User: 南島のミルフォードサウンドに行きたいです。壮大な景色を見てみたいです。自然に囲まれてリフレッシュしたいです。
System: ミルフォードサウンドは本当に美しい場所ですね！他にも何かアクティビティが気になりますか？
User: ハイキングやトレッキングにも興味があります。自然の中を歩くのは気持ちが良いですし、家族みんなで楽しめると思います。
System: ハイキングやトレッキングは素晴らしいですね！どんなコースが気になりますか？
User: トラックワイカトゥに行ってみたいです。美しい景色と多様な自然が楽しめると聞いています。家族で挑戦するのが楽しみです。
System: トラックワイカトゥ、素晴らしい選択ですね！他にも行きたい場所はありますか？
User: アイスランドにも行ってみたいです。美しい自然やオーロラを見てみたいです。新しい体験ができるのが楽しみです。
System: アイスランドのオーロラ、魅力的ですね！特にどの時期に行きたいですか？
User: 冬の時期、特に12月から2月に行きたいです。オーロラが見えるチャンスが高いと聞いています。寒いのは苦手ですが、魅力的です。
System: アイスランドの冬は特別ですね！他に旅行での楽しみ方はありますか？
User: 地元の食文化を楽しむのも好きです。新しい料理を試すのが楽しみですし、家族と一緒に食事をするのが大切です。
System: 地元の食文化を楽しむのは素敵ですね！特に好きな料理はありますか？
User: シーフード料理が好きです。新鮮な魚介類を味わうのが楽しみです。旅行先の特産品を試すのが好きです。
System: シーフード料理は美味しいですよね！最近、印象に残った料理はありますか？
User: ハワイで食べたポケが印象に残っています。新鮮な魚と野菜が絶妙でした。家族みんなで楽しみました。
System: ポケ、美味しそうですね！他におすすめの料理はありますか？
User: ハワイのロコモコもおすすめです。ご飯の上にハンバーグと目玉焼きが乗っていて、ボリューム満点です。家族も喜んで食べていました。
System: ロコモコ、ボリュームがあって美味しそうですね！他に食べてみたい料理はありますか？
User: ニュージーランドのラム肉料理を試してみたいです。新鮮な食材を使った料理が多いと聞いています。楽しみです。
System: ラム肉料理、楽しみですね！他に好きな食材はありますか？
User: 新鮮な野菜が好きです。特にトマトやアボカドを使った料理が好みです。サラダにするのも好きです。
System: 新鮮な野菜を使った料理は健康的ですね！お気に入りのサラダレシピはありますか？
User: シンプルなトマトとアボカドのサラダが好きです。オリーブオイルとレモンをかけて、塩で味付けします。とても美味しいです。
System: システム: シンプルで美味しそうなサラダですね！旅行中に作ることはありますか？
User: 旅行中はあまり料理はしませんが、簡単なサラダを作ることはあります。新鮮な食材を使うと、特別な味わいになります。
System: 旅行中に新鮮な食材を使った料理は特別ですね！次の旅行はいつ頃予定していますか？
```
